## Kaise use karo

1. Problem khud solve karne ki **poori koshish** karo — chalne waala code, test
   ke saath. Time-box: easy 15 min, medium 35, hard 60+.
2. Atak gaye → problem file ka `<details>` kholo (approach hint), phir dobara
   try.
3. Ho gaya / phir bhi atke → yahan solution dekho. Apne solution se compare —
   sirf "chal gaya" nahi, **complexity, edge cases, aur woh trap** jo problem
   test kar raha tha.
4. Ek hafte baad **bina dekhe** dobara solve karo. Recall = learning.
