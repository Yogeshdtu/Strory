# 01 — PROGRAMMING BASICS (PHASE 0)

## Prerequisites
**Kuch nahi.** Bilkul kuch nahi. Bas `00-START-HERE/03-setup-your-machine.md` follow karke
compiler install kar lo.

## Yeh folder kyun

Zyada tar C++ courses yahan se shuru hote hain:

> "C++ ek object-oriented programming language hai. Chalo Hello World likhte hain."

Aur beginner soch raha hota hai: *"bhai object-oriented kya hai? language kya hai?
compiler kya hai? yeh terminal wali black screen kya hai?"*

Yeh folder **wahi sab sawal** answer karta hai. Ek bhi line C++ code likhne se pehle.

Agar aapko already pata hai ki compiler kya hai, program kya hai, binary kya hai —
to aap yeh folder 30 minute mein skim karke aage badh sakte ho. Lekin
`08-what-happens-when-you-press-run.md` aur `10-bits-bytes-binary.md` zaroor padhna,
kyunki wo aage bahut kaam aayenge.
