Aur compiler installed hona chahiye (`00-START-HERE/03-setup-your-machine.md`).

## Yeh folder kyun

Ab aap **pehla C++ program** likhoge.

Lekin hum ise doosre courses ki tarah nahi karenge — "yeh code copy karo, chal gaya, next".

Hum us 6-line ke program ke **har ek character** ko todenge. Har `#`, har `<`, har `;`,
har `{`. Kyunki jo cheez aapko yahan clear ho jayegi, woh agle 2 saal aapke kaam aayegi.

Aur jo cheez yahan dhundhli reh gayi, woh 2 saal tak confuse karegi.
